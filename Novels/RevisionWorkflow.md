# Revision Workflow — Systematic Self-Editing Process

---

## 1. THE FOUR-PASS SYSTEM

Do NOT edit while writing. Write first, then revise in four passes.

### Pass 1: Structure Pass (read whole draft)
- [ ] Does the plot arc work? (setup → rising → crisis → resolution)
- [ ] Are all scenes necessary? (kill your darlings)
- [ ] Is the pacing right? (alternating high/low tension)
- [ ] Are there plot holes? (continuity errors, impossible timelines)
- [ ] Does every chapter end with a hook? (verify against AddictionMechanics.md)
- [ ] Is the climax satisfying? (earned, not deus ex machina)
- [ ] Is the ending earned? (character growth shown, not stated)

**Fix:** Move, cut, or merge scenes. Add bridging material where needed.

### Pass 2: Character Pass
- [ ] Does each character have a distinct voice? (could you identify them without tags?)
- [ ] Does the protagonist's flaw drive early chapters?
- [ ] Does the protagonist grow by the end? (specific behavioral change)
- [ ] Are character motivations clear? (why do they do what they do?)
- [ ] Do secondary characters have arcs? (even minor ones)
- [ ] Does the antagonist have a reason? (no mustache-twirling villains)
- [ ] Are relationships earned? (love doesn't happen at first sight — show why)

**Fix:** Add scenes showing motivation. Rewrite dialogue for voice consistency. Deepen antagonist.

### Pass 3: Prose Pass (line-level)
- [ ] Cut every unnecessary word (وہ, یہ, کہ, جو — if removable, remove)
- [ ] Replace "telling" with "showing" (see EmotionPatterns.md → Section 4)
- [ ] Vary sentence length (short for action, long for reflection)
- [ ] Remove adverbs (بہت, زیادہ, بالکل) — show intensity through action
- [ ] Check Urdu authenticity (no translation-sounding phrases)
- [ ] Read aloud — does it flow?
- [ ] Cut clichés: "دل دھڑکنا", "آنکھیں چار ہونا" — use once or rephrase

### Pass 4: Technical Pass
- [ ] Spelling and grammar (specific check for Urdu)
- [ ] Consistent script (Nastaliq-friendly throughout)
- [ ] Consistent character names (no switching شاید/شایدہ)
- [ ] Dialogue punctuation consistent
- [ ] Chapter titles and numbering correct
- [ ] Scene breaks (---) consistent

## 2. BETWEEN-DRAFT COOLDOWN

After each draft, step away for minimum:
- **Short story/novella:** 1 day
- **Novel (~300 pages):** 1 week
- **Epic (~1000+ pages):** 2 weeks

Return with fresh eyes. You'll catch problems you were blind to.

---

## 3. THE "COLD READ" TEST

Before finalizing, give chapter 1 to someone unfamiliar with the story:
- Did they want to read chapter 2?
- What did they predict would happen? (you want them close but wrong)
- Where did they get bored?

---

## 4. DRAFT TRANSITION CHECKLIST

| From | To | What to Check |
|------|----|---------------|
| Scene outline | First draft | Did I hit every beat from SceneBuilder? |
| First draft | Second draft | Plot holes? Character consistent? |
| Second draft | Third draft | Prose quality — show vs tell? |
| Third draft | Final | Technical polish — grammar, spelling, formatting |

## 5. COMMON PROBLEM FIXES

### Problem: Chapter feels slow
**Fix:** Cut first 2 paragraphs. Start later. Use 7-page tension cycle from AddictionMechanics.md.

### Problem: Dialogue feels flat
**Fix:** Give each character a different goal in every conversation. Conflict drives dialogue.

### Problem: Character feels inconsistent
**Fix:** Create a voice card (see CharacterBible.md → Section 4). Check every line against it.

### Problem: Reader won't care about the stakes
**Fix:** Show what character stands to lose. Make it specific and personal (not abstract).

### Problem: The romance feels unearned
**Fix:** Add scenes where they see each other's vulnerability. Love grows from shared vulnerability.

### Problem: The climax falls flat
**Fix:** Raise stakes in the previous chapter. Make the outcome uncertain. Protagonist should almost lose.

### Problem: The ending is too tidy
**Fix:** Leave one thing unresolved. Real life doesn't wrap up neatly.
