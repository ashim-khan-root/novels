# Opening Hook Bank — Killer First Lines & First Paragraphs

---

## 1. FIRST-LINE TYPES

### 1.1 Action
The reader is thrown into movement.

```
وہ بھاگ رہی تھی۔ پیچھے مڑ کر نہیں دیکھا، رکی نہیں، سانس لینے کی بھی فرصت نہیں تھی۔
She was running. Didn't look back, didn't stop, didn't have time to breathe.
```

### 1.2 Mystery/Question
A statement that demands explanation.

```
وہ جسے سب قاتل کہتے تھے، وہ دراصل اتنا بےگناہ تھا جتنا اس کا قتل شدہ بھائی۔
The one everyone called a murderer was as innocent as his murdered brother.
```

### 1.3 Bold Statement/Opinion
Protagonist's worldview stated directly.

```
زارا کو یقین تھا کہ محبت صرف ناولوں میں ہوتی ہے۔ حقیقت میں صرف وعدے ہوتے ہیں اور پھر ان کا بوجھ۔
Zara believed love only existed in novels. In reality, there were only promises and their weight.
```

### 1.4 Unusual Detail
An image so specific the reader must know more.

```
اس نے پچھلے تین دنوں میں ایک ہی درخت بنایا تھا — جڑیں مضبوط، شاخیں مرجھائی ہوئی، اور ہر بار وہی درخت۔
She had painted the same tree for three days — roots strong, branches withered, and every time the same tree.
```

### 1.5 Dialogue Opener

```
"تمہیں نہیں جانا چاہیے۔"
"کیوں؟"
"کیونکہ وہ تمہیں مار ڈالے گا۔"
"You shouldn't go."
"Why?"
"Because he'll kill you."
```

### 1.6 Setting as Mood
A description that immediately establishes emotional atmosphere.

```
اسلام آباد کی سرد صبح تھی۔ مارگلہ کی پہاڑیوں پر دھند کا ایک ہلکا سا پردہ تھا، جیسے کسی نے شہر کو رضائی میں لپیٹ دیا ہو۔
It was a cold morning in Islamabad. A thin veil of fog over the Margalla hills, as if someone had wrapped the city in a blanket.
```

### 1.7 Reverse Expectation
Start with what SHOULD be happy, but isn't.

```
شادی کا دن تھا۔ مگر وہ رو رہی تھی۔
It was her wedding day. But she was crying.
```

## 2. FIRST PARAGRAPH STRUCTURE

The opening paragraph must deliver:

```
Line 1:   HOOK — grab attention
Line 2-3: CHARACTER — someone we care about
Line 4-5: SITUATION — what's happening
Line 6:   TONE — what kind of story this is
No line wasted on weather, backstory, or description that doesn't serve the above.
```

### Example Structure

```
[HOOK] وہ نہیں جانتی تھی کہ آج اس کی زندگی بدلنے والی ہے۔
[CHARACTER] زارا کھڑکی کے پاس کھڑی تھی، ہاتھ میں کافی کا کپ تھا جو ٹھنڈی ہو چکی تھی۔
[SITUATION] اس نے پچھلے تین دنوں میں ایک ہی درخت بنایا تھا — جڑیں مضبوط، شاخیں مرجھائی ہوئی۔
[TONE] کینوس پر وہ درخت تھا، مگر حقیقت میں وہ خود تھی۔
```

## 3. FIRST LINES BANK (by Genre)

### Spiritual Romance

```
1. اس نے کبھی سوچا نہیں تھا کہ سجدے میں بھی آنسو بہائے جا سکتے ہیں۔
2. وہ اللہ سے دور بھاگ رہی تھی، مگر اللہ اس کے پیچھے تھا۔
3. نماز وہ پڑھتی تھی مگر دل وہاں نہیں تھا۔ وہ جانتی تھی۔
4. جب وہ پہلی بار کعبہ گئی تو اسے لگا جیسے وہ گھر آ گئی ہے۔
5. اس کا ایمان بکھرا پڑا تھا — اور وہ اسے جمع کرنا نہیں جانتی تھی۔
```

### Crime-Thriller

```
1. قتل ہوا تو سب نے اسے قاتل کہا۔ مگر وہ بےگناہ تھا۔
2. وہ جیل میں اٹھی تو اسے یاد نہیں تھا کہ وہ وہاں کیوں ہے۔
3. خون کا دھبہ فرش پر تھا، اور گواہ صفر۔
4. اس نے قتل نہیں کیا تھا۔ مگر اس کے پاس ثبوت نہیں تھا۔
5. عدالت نے اسے عمر قید سنائی۔ اس دن وہ پچیس سال کا تھا۔
```

### Murder Mystery

```
1. جب وہ مردہ ملا تو اس کے چہرے پر مسکراہٹ تھی۔ قاتل اسے جانتا تھا۔
2. پہلی بار جب اس نے لاش دیکھی تو وہ چیخی نہیں۔ وہ سوچنے لگی۔
3. تین دن پہلے وہ زندہ تھا۔ آج اس کی میت تھی۔ اور کل قاتل مل جائے گا۔
4. موت کوئی حادثہ نہیں تھی۔ یہ قتل تھا — اور ہر ایک کا کوئی نہ کوئی مقصد تھا۔
5. اس نے قتل کرنے کا سوچا بھی نہیں تھا۔ مگر اب لاش اس کے سامنے تھی۔
```

### Historical Fiction

```
1. تقسیم ہند کا فیصلہ ہو چکا تھا۔ مگر گھر والوں کو ابھی پتہ نہیں تھا۔
2. وہ گاؤں جو کبھی اس کا گھر تھا، آخری بار دیکھ رہی تھی۔
3. جنگ ختم ہو چکی تھی مگر وہ ابھی تک اپنے گھر نہیں پہنچا تھا۔
4. 1947 تھا، اور اس کا پورا وجود پوچھ رہا تھا — کہاں جائیں؟
5. جب وہ پناہ گزینوں کی قطار میں کھڑی تھی، اسے وہ گھر یاد آیا جو کبھی تھا۔
```

### Class-Divide Romance

```
1. وہ امیر تھا، وہ غریب تھی، اور یہ دونوں کے لیے مسئلہ تھا۔
2. "تم اس لائق نہیں ہو،" اس کی ساس نے کہا۔ اور وہ یقین کرنے لگی تھی۔
3. اس نے اسے پہلی بار دیکھا تو سوچا — یہ وہی ہے جس سے مجھے نفرت کرنی چاہیے۔
4. وہ جس گھر میں پلی بڑھی تھی، اس میں چھت سے پانی ٹپکتا تھا۔ اس کے گھر میں سوئمنگ پول تھا۔
5. وہ اس سے محبت کرتی تھی۔ مگر یہ محبت ان کی گلی میں نہیں بکتی تھی۔
```

### General (All-Purpose)

```
1. وہ جس دن سے پیدا ہوئی، اس دن سے وہ اکیلی تھی۔
2. کبھی کبھی ایک پل پوری زندگی بدل دیتا ہے۔ یہ وہ پل تھا۔
3. اس نے وہ خط نہیں پڑھنا چاہیے تھا۔ مگر پڑھ لیا — اور اب واپسی نہیں تھی۔
4. "معاف کرنا،" اس نے کہا۔ اور یہ آخری لفظ تھا جو اس نے اس سے کہا۔
5. وہ جب اٹھی تو اسے پتہ نہیں تھا کہ آج اس کی زندگی کے تین اہم ترین فیصلے ہونے والے ہیں۔
```

## 4. FIRST CHAPTER CHECKLIST

- [ ] First line makes me want to read the second line
- [ ] First paragraph establishes character (not description)
- [ ] By page 1, I know the protagonist's flaw or situation
- [ ] By page 3, I care what happens next
- [ ] By page 5, I know what kind of story this is (genre/tone)
- [ ] Chapter 1 ends with a hook that makes me want Chapter 2

### The "Bookstore Test"
If a reader opens the book at page 1:
- Will they turn to page 2? (hook)
- Will they flip to check the back cover? (interest)
- Will they buy the book? (investment)

If not, rewrite the opening.
