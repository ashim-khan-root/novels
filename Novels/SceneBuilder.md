# Scene Builder — Individual Scene Planning Template

---

## 1. SCENE BLUEPRINT

Fill before writing every scene:

```
SCENE #:            (chapter.scene, e.g. 5.2 = Chapter 5, Scene 2)
CHAPTER:            
POV CHARACTER:      

GOAL:               (what does the POV character want this scene?)
CONFLICT:           (who/what opposes them?)
STAKES:             (what happens if they fail?)

EMOTIONAL BEAT:     (one: Hope/Fear/Love/Anger/Grief/Joy/Suspense/Peace/Confusion/Relief/Longing/Regret)
TENSION LEVEL:      (1-5, where 5 is highest)

SETTING:            
TIME OF DAY:        
MOOD:               (tense/peaceful/suspenseful/romantic/sombre)

START:              (one line — where does the scene begin?)
END:                (one line — where does it cut? what is the hook?)

WORD TARGET:        (estimated words)
```

## 2. SCENE ARCHETYPES

### 2.1 Opening Scene
```
Purpose: Hook reader, establish protagonist, set tone
Must include: 
- A compelling image or action (not description)
- Protagonist's flaw on display
- A question the reader wants answered
- Tone/genre established in first 3 lines
Length: Compact — hit hard, trust the reader to catch up
```

### 2.2 Confrontation Scene
```
Purpose: Raise stakes, reveal character through conflict
Structure: 
- Trigger (someone says/does something)
- Escalation (verbal or physical)
- Breaking point (someone says too much)
- Aftermath (silence, exit, or new understanding)
Hook: Relationship changed permanently
```

### 2.3 Revelation Scene
```
Purpose: Give reader new information that changes meaning
Structure:
- Build-up (character anticipates something)
- The reveal (letter, witness, discovery, confession)
- Processing (character reacts — emotional beat)
- New question raised
Hook: "If this is true, then what about...?"
```

### 2.4 Romantic Scene
```
Purpose: Build emotional intimacy between characters
Structure:
- Proximity forced (shared space, accident, chore)
- Guard drops (vulnerability shown)
- Moment of connection (silence, gesture, shared secret)
- Interruption (external or internal — "but we can't")
Hook: Longing unresolved
```

### 2.5 Action/Suspense Scene
```
Purpose: Adrenaline, danger, urgency
Structure:
- Calm before storm (false safety)
- Threat enters
- Chase/conflict/escape
- Narrow escape OR captured
Hook: Immediate danger unresolved
```

### 2.6 Internal/Reflection Scene
```
Purpose: Character processing, emotional depth, backstory
Structure:
- Solitude (alone or in crowd)
- Trigger (memory, object, sensory cue)
- Flashback/internal struggle
- Decision or realization
Hook: New resolve or new question
```

### 2.7 Transition Scene (brief)
```
Purpose: Move character from one place/state to another
Length: Minimal — just enough to feel connected
Technique: 
- One vivid detail anchors the transition
- Character's mood colors the description
Cut to next scene fast
```

---

## 3. SCENE STRUCTURE — MINI-ARC

Every scene, even a short one, must have:

```
OPENING (10%):
- Establish setting + POV goal in 1-3 lines
- No lengthy descriptions — one sensory anchor

MIDDLE (70%):
- Conflict: character tries → fails → adapts → tries again
- Dialogue or action carries the weight
- Emotional intensity rises

END (20%):
- Result of conflict (success/failure/revelation/reversal)
- New question or new problem
- Cut — don't linger
```

---

## 4. SCENE OPENING TECHNIQUES

Don't start with description. Start with:

```
1. ACTION: "اس نے دروازہ زور سے کھولا اور اندر جھانکا۔"
2. DIALOGUE: "تم کہاں تھے؟" اس کی آواز میں غصہ تھا۔
3. INTERNAL: "وہ جانتی تھی کہ یہ غلط ہے۔ مگر وہ رک نہیں سکتی تھی۔"
4. SENSORY: "بارش کی بوندیں کھڑکی سے ٹکرا رہی تھیں، اور وہ سو نہیں پا رہی تھی۔"
5. MID-SCENE: Plunge reader into ongoing action — no warmup.
```

### Rules for Openings
- No weather descriptions as opening unless weather IS the conflict
- No waking up and starting the day (cliché)
- No mirror descriptions (cliché)
- No "she thought about what happened yesterday" (info-dump)

---

## 5. SCENE ENDING CHECKLIST

- [ ] Scene ends NOT when the action ends, but at the emotional peak
- [ ] Last line creates forward momentum (curiosity, worry, anticipation)
- [ ] If scene resolves fully, reader can put the book down — DON'T resolve fully
- [ ] Every scene ends with: "and now what?"

| Scene Type | Dialogue % | Narrative % | Internal % |
|------------|-----------|-------------|------------|
| Confrontation | 70% | 10% | 20% |
| Romantic | 40% | 30% | 30% |
| Action/Suspense | 20% | 70% | 10% |
| Internal/Reflection | 10% | 20% | 70% |
| Revelation | 30% | 30% | 40% |
| Transition | 0% | 100% | 0% |

---

## 7. SCENE SEQUENCE CHECK — DOES THIS SCENE BELONG?

Ask before committing to write a scene:

1. Does it advance plot OR develop character? (if no → delete)
2. Would the story break if I removed it? (if no → delete or merge)
3. Does it have conflict? (no conflict = no scene)
4. Does it end with a hook? (if transitional, cut to minimum)
5. Is there a more efficient way to deliver this information? (dialogue > internal monologue > narrative)
